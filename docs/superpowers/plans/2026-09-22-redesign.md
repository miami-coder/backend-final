# Redesign «Вечірній бар» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Повний візуальний редизайн застосунку «Пиячок» на темну теплу систему «Вечірній бар» (Unbounded + Golos Text) без зміни логіки, роутів і API-шарів.

**Architecture:** Зміни йдуть знизу вгору: токени Tailwind 4 `@theme` + шрифти через `next/font` → UI-примітиви → лейаут-компоненти → фічі → механічний прохід по сторінках. Кожен шар будує на попередньому; логіка й тести не змінюються.

**Tech Stack:** Next.js 16.3.4, React 19, Tailwind CSS 4 (`@theme`), `next/font/google`, vitest.

**Spec:** `docs/superpowers/specs/2026-09-22-redesign-design.md` — читати разом із планом: токени, трактування компонентів, принципи.

## Global Constraints

- Тільки темна тема; перемикача немає. Фон `#171310`, поверхні `#211B15`/`#2B241C`.
- Шрифти: Unbounded — ЛИШЕ заголовки (h1–h3) і логотип; Golos Text — весь інший текст.
- Глибина — ієрархія поверхонь + `1px` бордери; без box-shadow як основного засобу, без декоративних градієнтів (дозволені тільки теплі градієнти-плейсхолдери фото).
- Кнопки/бейджі/пошук — пілюлі (`rounded-full`); картки/панелі/інпути — `rounded-xl` (12px).
- Primary-кнопка: бурштин `#F0B429` з темним текстом `#171310`, НЕ з білим.
- Анімація лише як відповідь на дію; `prefers-reduced-motion` — тільки opacity/color.
- Фокус видимий всюди (бурштинове `focus-visible` кільце).
- Кирилиця обох шрифтів обов'язкова (`subsets: ['latin', 'cyrillic']`).
- Логіка, тексти (копірайт українською), роути, API, Zod-схеми, тести — без змін.
- Після кожного таска: `pnpm lint && pnpm typecheck && pnpm test` — усе зелено, потім commit.
- Заборонені в коді після редизайну: `stone-*`, `bg-white`, `emerald-*`, `red-600`, `text-brand-*`, `bg-brand-*` (перевірка в Task 14).

## Мапа заміни класів (використовується в Task 11–13)

| Старий клас | Новий клас |
|---|---|
| `bg-white` | `bg-surface` |
| `bg-stone-50` / `bg-stone-100` | `bg-raised` |
| `bg-stone-200` | `bg-raised` |
| `border-stone-200` | `border-line` |
| `border-stone-300` | `border-strong` |
| `text-stone-900` / `text-stone-800` | `text-ink` |
| `text-stone-600` / `text-stone-500` / `text-stone-700` | `text-muted` |
| `text-stone-400` | `text-faint` |
| `hover:bg-stone-50` / `hover:bg-stone-100` | `hover:bg-raised` |
| `bg-brand-500` / `bg-brand-600` | `bg-amber-500` (текст кнопки → `text-espresso`) |
| `text-brand-500` / `text-brand-600` | `text-amber-500` |
| `hover:text-brand-600` | `hover:text-amber-400` |
| `focus:border-brand-500` | `focus:border-amber-500` |
| `bg-brand-100 text-brand-700` / `text-brand-800` | `bg-amber-400/15 text-amber-400` |
| `bg-emerald-100 text-emerald-700` | `bg-success/15 text-success` |
| `bg-red-600` / `bg-red-700` | `bg-danger` (текст → `text-espresso`) |
| `text-red-600` / `text-red-700` | `text-danger` |
| `rounded-lg` на кнопках/бейджах/пошуку | `rounded-full` |
| `rounded-lg`/`rounded-2xl` на картках/панелях/формах | `rounded-xl` |

Виняток: `rounded-lg` всередині `select` (стрілка) чи там, де елемент — не кнопка/бейдж/панель, рішення на місці за принципом «пілюлі для дій, 12px для поверхонь».

- [ ] **Step 2: RatingStars — розділити заповнені й порожні зірки**

```tsx
export function RatingStars({ value, count }: { value: number | null; count?: number }) {
  if (value === null) return <span className="text-sm text-faint">Немає оцінок</span>
  const rounded = Math.round(value * 2) / 2
  const chars = [1, 2, 3, 4, 5].map((i) => (rounded >= i ? '★' : '☆')).join('')
  const filled = chars.length - (chars.match(/☆/g)?.length ?? 0)
  return (
    <span className="inline-flex items-center gap-1" aria-label={`Рейтинг ${value} з 5`}>
      <span className="text-amber-500">{chars.slice(0, filled)}</span>
      <span className="text-strong">{chars.slice(filled)}</span>
      <span className="text-sm font-medium">{value.toFixed(1).replace('.', ',')}</span>
      {count !== undefined && <span className="text-sm text-muted">({count} відгуків)</span>}
    </span>
  )
}
```

(Логіка півзірки зі старого коду не працювала — `★` ставилось і для `>= i - 0.5`; нова версія просто розділяє заливку/контур, тести на aria-label/текст лишаються зеленими.)

### Task 7: Header — Unbounded-логотип, активна навігація

**Files:**
- Modify: `src/components/layout/header.tsx`

**Interfaces:**
- Consumes: `font-display`, `bg-surface`, `border-line`, `text-muted`, `text-ink`, `text-amber-500`, `text-amber-400`, `bg-amber-500`, `text-espresso`.
- Produces: Header з підсвіченим активним пунктом (usePathname).

- [ ] **Step 1: Переписати розмітку (логіка пошуку не змінюється)**

```tsx
'use client'

import Link from 'next/link'
import { usePathname, useRouter } from 'next/navigation'
import { useUser } from '@/components/providers/user-provider'
import { UserMenu } from '@/components/layout/user-menu'

const NAV = [
  { href: '/', label: 'Каталог' },
  { href: '/news', label: 'Новини' },
  { href: '/hangouts', label: 'Зустрічі' },
]

export function Header() {
  const { user } = useUser()
  const router = useRouter()
  const pathname = usePathname()

  return (
    <header className="border-b border-line bg-surface">
      <div className="mx-auto flex max-w-6xl items-center gap-5 px-4 py-3">
        <Link href="/" className="font-display text-base font-bold text-amber-500">Пиячок</Link>
        <nav className="flex gap-4 text-sm">
          {NAV.map((item) => {
            const active = pathname === item.href
            return (
              <Link
                key={item.href}
                href={item.href}
                aria-current={active ? 'page' : undefined}
                className={`border-b-2 pb-0.5 transition-colors ${
                  active ? 'border-amber-500 text-ink' : 'border-transparent text-muted hover:text-amber-400'
                }`}
              >
                {item.label}
              </Link>
            )
          })}
        </nav>
        <form
          className="ml-auto hidden sm:block"
          onSubmit={(e) => {
            e.preventDefault()
            const q = new FormData(e.currentTarget).get('q')
            router.push(`/?q=${encodeURIComponent(String(q ?? ''))}`)
          }}
        >
          <input
            name="q"
            placeholder="Пошук закладів…"
            aria-label="Пошук закладів"
            className="w-56 rounded-full border border-strong bg-bg px-4 py-1.5 text-sm text-ink placeholder:text-faint focus:border-amber-500 focus:outline-none"
          />
        </form>
        {user ? <UserMenu /> : (
          // Посилання, а не Link>Button: <button> всередині <a> — невалідний HTML.
          // Класи — як primary-кнопка (sm).
          <Link
            href="/auth/login"
            className="inline-flex items-center justify-center gap-1.5 rounded-full bg-amber-500 px-3 py-1 text-sm font-medium text-espresso transition-colors hover:bg-amber-400"
          >
            Увійти
          </Link>
        )}
      </div>
    </header>
  )
}
```

```ts
// Теплі градієнти відтінків дерева для плейсхолдерів фото (см. спек §3);
// варіюються за id закладу, щоб сітка не виглядала монотонною
const PLACEHOLDER_GRADIENTS = [
  'linear-gradient(135deg,#4a3b28,#2c241c)',
  'linear-gradient(135deg,#5a4426,#332617)',
  'linear-gradient(135deg,#6b4a2a,#3d2a18)',
  'linear-gradient(135deg,#584032,#2f231a)',
]

export function placeholderFor(id: string): string {
  const h = [...id].reduce((acc, ch) => acc + ch.charCodeAt(0), 0)
  return PLACEHOLDER_GRADIENTS[h % PLACEHOLDER_GRADIENTS.length]
}
```
