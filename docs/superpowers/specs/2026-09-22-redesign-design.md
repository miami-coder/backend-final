# Дизайн-док: повний редизайн «Пиячок» — напрямок «Вечірній бар»

Дата: 2026-09-22
Статус: погоджено з замовником (напрямок A, типографіка 3, темна-лише, весь застосунок)

## 1. Контекст

Поточний фронтенд виглядає шаблонно: системні шрифти, білі картки на `stone`-бордерах,
світлий фон, емодзі-плейсхолдери. Користувачі не звертають увагу на застосунок.
Мета — характерний, «преміальний на дотик», але легкий дизайн у мові барної культури,
без обтяження інтерфейсу. Функціональна частина не змінюється: усі 23 сторінки
(каталог, заклади, новини, зустрічі, акаунт, авторизація, адмінка) зберігають
ту саму логіку, роути й API-шари; змінюється лише візуальний шар.

## 2. Зафіксовані рішення

1. **Напрямок** — «Вечірній бар»: темна теплота (еспресо/дерево), бурштин для дій,
   мідь для акцентів. Атмосфера бару ввечері; контрастний, але теплий dark-mode.
2. **Типографіка** — Unbounded (тільки заголовки + логотип, weights 500–700) +
   Golos Text (увесь текст, 400–700). Обидва з повною кирилицею.
3. **Тема** — виключно темна; перемикача теми немає.
4. **Охоплення** — весь застосунок, включно з адмінкою й age-gate; одна система
   компонентів скрізь.

## 3. Токени дизайну (Tailwind 4 `@theme`)

### Палітра

| Токен           | Значення  | Роль                                       |
|-----------------|-----------|--------------------------------------------|
| `--color-bg`    | `#171310` | Фон сторінки (espresso)                    |
| `--color-surface`| `#211B15` | Картки, панелі, хедер                      |
| `--color-raised`| `#2B241C` | Піднята поверхня (hover, модалки, дропдауни)|
| `--color-line`  | `#3A3128` | Розділювачі, бордери                       |
| `--color-strong`| `#4A4038` | Активний бордер (інпути, обведені бейджі)  |
| `--color-ink`   | `#F3E9DB` | Основний текст (кремовий)                  |
| `--color-muted` | `#B3A493` | Другорядний текст                          |
| `--color-faint` | `#8A7D6D` | Третинний текст (підписи, футер)           |
| `--color-amber-*`| 50–900   | Дія/CTA (основний `#F0B429`, hover `#FFCA4D`) |
| `--color-copper-*`| 50–900  | Акценти (основний `#C1681A`)               |
| `--color-success`| `#8AA861` | Успіх, «схвалено», онлайн                  |
| `--color-danger`| `#D9634D` | Помилки, видалення, скарги                 |

Стара гама `--color-brand-*` замінюється: `brand` → `amber` (дії), мідь — окремо.
Статусні кольори — теплі відтінки (зеленувато-оливковий, теракотовий), не чисті
green/red з дефолтного Tailwind.

### Типографіка

- Шрифти підключаються через `next/font/google` (Unbounded, Golos Text) у
  `src/app/layout.tsx` зі `subset: ['latin', 'cyrillic']`, CSS-змінні → `@theme`:
  `--font-display`, `--font-sans`.
- `--font-display` (Unbounded): h1 `clamp(1.75rem, 4vw, 2.5rem)` w700, h2 `1.25–1.5rem`
  w600, логотип. **Ніколи** в довгих текстах, підписах чи числах.
- `--font-sans` (Golos Text): body 14–16px w400, бейджі/кнопки w600, 12–13px для метаданих.
- Міжрядковий: заголовки 1.15–1.2, текст 1.5+.

### Форма, глибина, рух

- Радіуси: картки/панелі/інпути `12px`, кнопки/бейджі/пошук — пілюлі (`rounded-full`).
- Глибина — виключно ієрархією поверхонь (bg → surface → raised) + `1px` бордери
  `line`; **без** box-shadow як основного засобу, без декоративних градієнтів.
- Кольорові заливки плейсхолдерів фото — теплі градієнти відтінків дерева
  (варіюються) замість емодзі 🍺.
- Анімація: тільки відповідь на дію — hover (бордер/поверхня), фокус-ринг бурштин,
  тости/модалки. `prefers-reduced-motion` поважаємо (переходи лише opacity/color).
- Фокус видимий всюди: `focus-visible` кільце бурштинового кольору.

## 4. Трактування ключових компонентів

- **Хедер**: фон `surface`, розділювач `line`; логотип «Пиячок» Unbounded 700 бурштином
  (без 🍺 у логотипі); активний пункт навіги — кремовий текст + бурштинове підкреслення;
  пошук — пілюля на `bg`.
- **Кнопки** (`button.tsx`): пілюлі; primary — бурштин з темним текстом `#171310`
  (не білим), hover — світліший бурштин; secondary — обведена на `strong`; ghost —
  бурштиновий текст; danger — теракотова заливка.
- **Бейджі**: чек (`≈ N грн`) — суцільний бурштин, типи закладу — обведені, статуси —
  тоновані (успіх/небезпека) напівпрозорими заливками.
- **Картка закладу**: `surface` + бордер `line`, hover — бордер бурштиновий + піднята
  поверхня; фото-плейсхолдер — теплий градієнт; назва кремова, адреса `muted`.
- **Age gate**: повноекранний еспресо-фон, Unbounded-логотип, чітке 18+ повідомлення.
- **Адмінка**: та сама система; таблиці/списки — рядки на `surface` з розділювачами
  `line`, статус-бейджі тоновані.

## 5. План реалізації (шари знизу вгору)

1. **Фундамент**: `globals.css` (нові `@theme`-токени, скидання старих), `layout.tsx`
   (next/font), `app-shell.tsx` (фон, відступи).
2. **UI-примітиви** (`src/components/ui/*`): button, badge, input, textarea, select,
   modal, toast, pagination, rating-stars, skeleton, empty-state.
3. **Лейаут-компоненти** (`src/components/layout/*`): header, footer, age-gate,
   admin-nav, user-menu.
4. **Фічі** (`src/components/features/*`): venue-card, venue-filters, картки відгуків,
   новин, зустрічей, форми.
5. **Сторінки**: прохід по всіх `page.tsx` — заміна застиглих `stone-*`/`white`/
   `bg-*` класів на токени; переважно механічна правка.
6. **Очищення**: видалення емодзі-плейсхолдерів, перевірка контрасту й фокус-станів.

## 6. Обмеження і ризики

- Кирилиця обох шрифтів підтверджена в Google Fonts.
- `next/font` не потребує мережі в рантаймі клієнта; у dev/CI завантажується на білді.
- Тести (`vitest`) перевіряють логіку/текст, не класи — редизайн їх не ламає; пробіг
  `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm build` після кожного шару.
- Контраст: кремовий `#F3E9DB` на `#171310` ≈ 14:1; `muted` ≈ 6:1 — WCAG AA виконано.
